# 工作空间扫描报告模板

每次扫描后用此结构对话回复用户。

```markdown
## 工作空间扫描报告（YYYY-MM-DD HH:MM）

### 总览
- 已注册：N 个（C盘 X / D盘 Y / E盘 Z）
- 聚合目录裸目录：M 个未注册

### 与上次清单对比
- ✅ 新增已注册：xxx
- ⚠️ 新增裸目录（待登记）：xxx
- ❌ 已消失：xxx（路径不存在）
- 🔄 用途变更：xxx（memory 里口径变了）

### 已注册空间清单（仅列变化项，未变的不重复）

| 名称 | 路径 | 用途 |

### 裸目录清单（按用途解读结果）

| 名称 | 路径 | 真实用途 | 数据源 |

### 操作建议
- WORKSPACES.md：[已自动更新 / 待确认]
- 裸目录登记：建议在 WorkBuddy 客户端手动打开 X / Y / Z 完成注册
```

## 风格要求

- 表格列宽尽量紧凑，路径放反斜杠原始格式
- 用途字段直接抄 memory.md 的关键句，不要瞎概括
- 用 emoji 区分变化类型（✅ ⚠️ ❌ 🔄）便于快速扫读
- 末尾给"操作建议"段落，明确告诉用户落盘状态和下一步
